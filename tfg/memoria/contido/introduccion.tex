\chapter{Introducción}

Las pequeñas y medianas empresas de transporte coordinan vehículos, conductores y envíos con información que a menudo queda repartida entre hojas de cálculo, mensajes y llamadas. Esta fragmentación dificulta saber qué recursos están disponibles, reconstruir el historial de un envío y detectar asignaciones incompatibles.

TransitOps plantea una aplicación web única para ese trabajo operativo. El interés del proyecto no reside únicamente en el producto final, sino en aplicar y documentar de forma disciplinada el ciclo de vida completo del software: elicitación, requisitos, diseño, implementación, verificación, despliegue y análisis de resultados.

El alcance se mantiene deliberadamente acotado para lograr una aplicación completa. Incluye usuarios con dos roles, catálogos de vehículos, conductores y clientes, envíos, asignaciones, estados, eventos y un resumen operativo. Quedan fuera la optimización de rutas, el GPS, la facturación, la aplicación móvil y el acceso de clientes externos.

Esta memoria se organiza según las fases del ciclo de vida, complementadas por un capítulo de desarrollo iterativo que conserva la evidencia de cada sprint. Así se puede estudiar tanto la solución técnica como la evolución que conduce hasta ella.
